# Class source strip — product decisions (locked)

Last updated: 2026-09-18

**Status:** Agreed direction for **book chips**. Notebook layout, ownership, and chip jobs live in **`NOTEBOOK_PRODUCT.md`**. Implementation phases for the strip itself: **`CLASS_SOURCE_STRIP_PHASED_PLAN.md`**.

**Teacher-facing:** no new named product. Chips on the open class.  
**Code name:** source strip.

**Related:** `NOTEBOOK_PRODUCT.md` (Notebook Pin / Tab / Overlay / Park; student-scoped store), `LESSON_HUB_AND_MULTI_BOOK_PRODUCT.md` (this is the near-term two-book swap; Hub stays later), `CLASSROOM_HOME_PRODUCT.md` (yellow Pick shelf stays for between-block close), `LESSON_BOARD_PRODUCT.md` (page model only).

---

## Why

The left rail already owns **tools**. Mid-class, switching books still means close the overlay → yellow shelf → open the other cover. That is a scene change, not a tab change.

The strip answers **where we are** and **one-tap swap**.

---

## Locked decisions

| Decision | Choice |
|----------|--------|
| Job | **Where we are** + **one-tap swap**. Not a second toolbox. |
| Tabs | Teaching **sources**: assigned books + Notebook |
| Left rail | Tools stay there (toolbox, translate, pen, settings, …) |
| Book tap | That book **Focus**; last page restored; overlay stays open |
| Close (X) / Esc | Still the yellow **shelf**. Strip is mid-class; shelf is between blocks |
| Notebook chip | **Tab** (notebook owns the desk). **Pin / Park** stay on the **left rail**. See `NOTEBOOK_PRODUCT.md`. |
| Notebook storage | **One notebook per student.** Not per book/unit. No mega-notebook across kids. |
| Book swap → notebook | PDF change **does not** swap the notebook |
| Height | Thin (~36px). Reserve top inset so the spread still fits |
| Clock / End | Same top row, tucked **right** of the chips (not on the strip as a tab) |
| Workshop reader | No strip (place bar already owns the top) |

```text
[ Workshop p.42 ]  [ Literature p.18 ]  [ Notebook ]     24:12  End
```

Chips sit on the **left** of the open-book top row. Time + End tuck on the **right** of that row so they cannot sit on the chips.

---

## Non-goals (this track)

- Lesson Hub carousel or `⌂ Hub` chip
- Focus book + Dock a second book / 50/50 split
- Window manager
- Typed class-log notebook (still dead; live surface is Notebook)
- Tools, streak, recap, or End class **as a strip tab** (End stays in the floating capsule, tucked right)

---

## Success

1. Two assigned books: tap the other chip → that PDF at last page; no yellow shelf.
2. Switch back → the first book’s page and ink are still there.
3. Notebook chip takes **Tab** (notebook owns the desk, book stays warm). Left-rail button Pins / Parks. Changing books does not load a different notebook.
4. X / Esc still returns to Pick shelf.
5. One-book student: strip still shows that book + Notebook; spread is not clipped.
